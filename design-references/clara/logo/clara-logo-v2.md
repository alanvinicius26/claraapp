## Prompt da logo

Use case: logo-brand.
Asset type: production website horizontal logo for a Brazilian beauty scheduling app and personal assistant named Clara, domain minhaclara.com.
Primary request: create one sophisticated, distinctive, professional logo replacing the old "Clara PRO" identity. The visible brand text must be exactly "clara" in lowercase. No other words.
Design: refined editorial serif wordmark, graceful but extremely legible, expertly kerned, balanced contrast with no fragile hairlines. Bespoke subtle curves, contemporary and warm rather than ornate wedding calligraphy. To its left, a compact original monogram using ONLY the letter C, with a continuous sculptural ribbon curve and a subtle open conversational shape. The mark and letters should feel like one carefully art-directed luxury software/beauty brand. No letter P, no CP, no MC. No calendar, no heart icon, no flower, no generic sparkle, no female portrait.
Composition: single horizontal lockup, symbol left, wordmark right, consistent optical baseline, generous but compact spacing, centered on a wide canvas, about 4:1 lockup aspect ratio. Whole identity fits within image without clipping. Minimal transparent margins; do not draw presentation boards or color swatches.
Color: solid deep burgundy #6e1936 for all nontransparent logo pixels, flat solid color, crisp anti-aliased edges. This mark must be usable as a single-color mask on cream or burgundy UI backgrounds. Actual fully transparent alpha background, not an opaque checkerboard, no background color.
Text (verbatim): "clara".
Avoid: PRO, Pro, pro, slogans, labels, dates, mockups, embossing, gradients, shadows, texture, decorative borders, multiple versions, extraneous letters.
Deliverable: a single high-resolution transparent PNG logo, wide landscape.

## Prompt do símbolo

Use case: background-extraction.
Asset type: square transparent app symbol and favicon.
Input image 1 is the edit target and exact design reference: the newly generated Clara logo.
Extract ONLY the existing burgundy ribbon-shaped C monogram at the left of this image. Preserve its exact curves, overlapping ribbons, proportions, burgundy color and artistic silhouette. Remove all of the word "clara" on the right. Do not redesign the symbol. Center this one existing C symbol in a square image with a small even transparent margin, approximately 8% on each side. No letters or words besides the C symbol. Absolutely no P, no CP, no calendar, no extra ornaments, no shadow. Actual transparent alpha background. Crisp clean edges. Output one transparent PNG, optimized composition for an app icon.
